# 招募音视频素材来源

只选取用户提供素材中已确认与通用追猫演出对应的部分。素材权利沿用原游戏权利归属，不属于本项目代码许可证的授权范围。

| 发布文件              | 来源                                                                                                                        | 处理                                                                                               |
| --------------------- | --------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------- |
| `chase-normal.mp4` / `chase-rare.mp4` / `chase-fes.mp4` | 用户提供的三档追猫片段 | 作为各档六段通用转场之前的有声首段；实际序列以 `lib/gacha-media.ts` 为准 |
| `reveal-bgm.m4a`      | `bgm_010050003_m.wav`                                                                                                       | AAC 160 kbps，约 84.39 秒，faststart                                                               |
| `reveal-standard.m4a` | 参考录像 31.0–34.5 秒 + `bgm_010050003_m.wav` 39.330–42.830 秒                                                              | 精确对齐并反相削弱背景音乐，保留普通角色原始揭晓音效；AAC 160 kbps                                 |
| `rare-impact.m4a`     | 已确认的三星冲击音源                                                                                                        | 用于三星演出冲击阶段                                                                               |
| `pool-loop.mp4`       | `本地素材库/gacha_00601_main.mp4`（已转好的高清单段）                                              | 从录像对应的 5 秒镜头开始重排循环，裁出卡池可见区域；576×640，H.264、YUV420P、faststart            |
| `gacha_black_gekota.mp4` | 用户提供的原版抽卡参考录像 f0165-f0167 | 仅裁出黑呱太白色像素插入与回到抱猫的 1920×1080 游戏视口，约 1.01 秒；H.264 + AAC 160 kbps、faststart，只用于 mystery 分支 |

两首音乐通过参考录像 7–24 秒、27–44 秒和 55–72 秒段落的频谱相关性核对。视频原音轨和背景音乐分开控制；视频缓冲或暂停时，追猫音乐同步暂停。

原始素材没有独立音效文件，因此普通与三星揭晓音效从用户提供的参考录像恢复。处理只削弱已确认的背景音乐源，不重新合成或冒充原版音色；少量录制混响可能仍然存在。

媒体白名单位于 `lib/gacha-media.ts`，构建与测试检查该清单，不发布其他音视频。三星画面由原始 UI 图片、特效精灵和逐角色 Cutin 实时组合，不用录像画面或 134 组宽幅动画；揭晓音效按用户确认采用参考录像截取。没有复制原始 WAV、完整参考录像、抽帧、FFmpeg 工具、压缩包或整个资源库。唯一的录像画面例外是黑呱太分支的 1.01 秒通用插入片；它是当前缺少独立原资源时的定点替代，不用于角色揭示。MP4 / M4A 是最终发布资源，普通构建无需再次转码。

卡池入口以参考录像 0.2 秒处的完整原始 16:9 游戏画面作为定位底板。左半区改用 `gachabg_00601` 的高清原始动画；右半区叠加 `gacha_000000601.png`、`gacha_promotion_label_000000601_01.png` 和原版按钮部件。页面通过 CSS 排除模拟器窗口栏，单抽、十抽、详情、左右切换和 Lineup 都是独立交互控件。不会发布完整录像或资源库。

抽查的 `gachaadscutin` 包含技能展示和联动宣传片，不能仅凭文件名就当作招募揭晓。尚未确认映射与用途的资源不加入发布目录。
